FONTLOG for Kallar
==================

Kallar is an aperture-variable multiscript display family. Every branch is
built on the Manjari skeleton (OFL 1.1): Manjari supplies the shared Latin,
digits, punctuation, symbols, spacing, metrics and design language. The
Devanagari, Tamil, Telugu and Kannada branches use the corresponding Noto Sans
faces only as script donors, because Manjari has no glyphs for those scripts.
All branches add the Petal/Aperture transformation, a variable APER axis, and
COLRv1 blue→orange Spectrum builds.

2026-11-09 — v1.200 (Manjari Base)
----------------------------------
- Rebuilt all five families on the Manjari base. Manjari now supplies the
  shared Latin, digits, punctuation, symbols, spacing, metrics, x-height,
  cap-height and Latin kerning of every family.
- The Devanagari, Tamil, Telugu and Kannada branches use Noto Sans only as
  script donors for the script-specific letter structures Manjari does not
  contain. Donor weights are calibrated to Manjari's pen: wght 360/550 for
  Devanagari, Tamil and Kannada; 340/500 for Telugu.
- Moved the Noto files from `sources/base/` to `sources/donors/`; added
  `sources/donors/README.md` and updated the derivative-model documentation.
- All families use Manjari's typo metrics 800/-300 with automatic win metrics
  sized to each script's outline extents. OS/2 x-height and cap-height now
  follow Manjari.
- Manjari's Latin `kern` lookups are merged into each script family's GPOS.
- Manjari composites are flattened when transplanted, fixing fontbakery's
  nested-components check.
- Tests now assert Manjari's shared-glyph outlines, advances, spacing and
  kerning in every family.
- Regenerated all fonts, specimens, proofs and PDFs. Fontbakery: 0 FAIL on
  all eight multiscript Regular/Bold variable fonts.
- Reproducible builds remain byte-identical.

2026-11-09 — v1.100 (Kallar Multiscript)
---------------------------------------
- Renamed the family from Ezhuthu Kamalam to Kallar. The v1.000 entry below is
  the historical Malayalam release under the former name.
- Renamed the GitHub repository from `ezhuthu` to `kallar`; old URLs redirect.
- Added Kallar Devanagari, Tamil, Telugu and Kannada.
- Each family: variable Regular and Bold with APER 0–100, static Round/Petal/
  Bold Petal instances, and COLRv1 Spectrum Regular/Bold builds.
- Same point-preserving aperture engine, with script-specific profiles:
  Devanagari absolute headline freeze; Tamil gentle profile; Telugu and
  Kannada full loop warp.
- Script glyph sets computed through the GSUB closure so Latin stays in the
  base style.
- Devanagari metrics: typo 1000/-408, win 1397/580 (Regular), 1398/597 (Bold).
  Tamil/Telugu/Kannada keep their base typographic ascenders and auto win
  metrics.
- New multiscript specimen (HTML + vector PDF), axis grid, hero poster and
  four script sheets.
- Tests: axes, metadata, shaping across APER, cmap coverage, outline
  variation, Latin guard, static instances and COLRv1 for all four scripts.
- Fontbakery: 0 FAIL on the eight new Regular/Bold VFs with the documented
  custom-axis / STAT-length / Bold exclusions.

2026-11-09 — v1.000 (Kamalam, now Kallar)
-----------------------------------------
- First production release of Ezhuthu Kamalam.
- Variable Regular and Bold fonts with the custom APER (Aperture) axis,
  0 = round, 50 = bloom, 100 = petal (default).
- Point-compatible masters generated by a capped petal warp; static Round,
  Petal and Bold Petal instances included.
- Ezhuthu Kamalam Spectrum: COLRv1/CPAL blue→orange gradient builds in
  Regular (913 colour glyphs) and Bold (907 colour glyphs), both with a
  7-colour palette.
- 1000 UPM, full Malayalam block + Latin, Manjari GSUB/GPOS preserved.
- New metrics: typo 800/-300, win 1100/700, USE_TYPO_METRICS.
- Self-contained HTML specimen, hero/axis/gradient/glyph-sheet PNG proofs.
- Tests: axes, shaping across APER, coverage, colour tables, legacy draft.
