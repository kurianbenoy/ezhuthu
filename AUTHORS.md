# Authors & credits

## Kallar

- **Design, aperture engine, variable font, Spectrum build, specimen:**
  Kallar Project Authors, 2026.
- **Base skeleton for every family:** Manjari by **Santhosh Thottingal** and
  **Swathanthra Malayalam Computing** (SMC), Copyright 2018 The Manjari
  Project Authors. Licensed under the SIL Open Font License 1.1.
  <https://gitlab.com/smc/fonts/manjari>
  Manjari supplies the shared Latin, digits, punctuation, symbols, spacing,
  metrics and design language of all five Kallar families.
- **Devanagari, Tamil, Telugu and Kannada script donors:** Noto Sans
  Devanagari, Noto Sans Tamil, Noto Sans Telugu and Noto Sans Kannada by
  **The Noto Project Authors**, Copyright 2022. Licensed under the SIL Open
  Font License 1.1. <https://github.com/notofonts>
  The donors supply only the script-specific letter structures that Manjari
  does not contain; they are not the base of the family.
- **Legacy v0.2 parametric draft / shaping engine:** adapted from
  **Nupuram** by Santhosh Thottingal / SMC, Copyright 2023 The Nupuram Project
  Authors, MIT. <https://gitlab.com/smc/fonts/Nupuram>
- **Sarvam inspiration:** the blue → orange spectrum and the gateway/lotus
  visual language are an homage to [Sarvam AI](https://www.sarvam.ai/brand).
  This project is independent and is not affiliated with or endorsed by
  Sarvam AI.
