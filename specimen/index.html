01 / The axis

തുറക്കുന്ന വാതിൽ

The Aperture axis. Every counter is a gateway.

Malayalam is a script of loops. Ezhuthu Kamalam treats each loop as a threshold: at APER 0 it is the classic round Manjari loop; at APER 100 the crown rises into a soft lotus point. Drag the slider — the same outlines, one continuous transformation.

02 / Colour

നിറങ്ങളുടെ ഒഴുക്ക്

A blue-to-orange spectrum, carried inside the font.
ഭാഷയുടെ സാധ്യതകൾ
എല്ലാവർക്കും വേണ്ടിയുള്ള എഐ

The Ezhuthu Kamalam Spectrum build uses a COLRv1 PaintLinearGradient clipped to each glyph. Blue sits at the crown, orange at the baseline, gold in the descenders, so a paragraph reads as one continuous field rather than a set of coloured letters. The sample above uses CSS gradient clipping so it works in every browser; the downloadable font carries the same gradient in its COLR/CPAL tables.

An open-source Malayalam display family by the Ezhuthu Project Authors. The skeleton is based on Manjari by Santhosh Thottingal and Swathanthra Malayalam Computing, used under the SIL Open Font License 1.1. The aperture engine, variable axis, spectrum build and specimen are new work.

The blue-to-orange spectrum is an homage to the visual language of Sarvam AI. This project is independent and is not affiliated with or endorsed by Sarvam AI. The name “Ezhuthu” means “writing”; “Kamalam” means “lotus”.
